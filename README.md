# Spring Java Hands-On

A comprehensive collection of hands-on projects developed while learning the Spring ecosystem. This repository demonstrates practical implementation of core Spring concepts, Spring Boot, Spring Data JPA, Hibernate, Maven, and RESTful web services through structured exercises.

The primary objective of this repository is to strengthen backend development skills by building real-world Java applications using industry-standard frameworks and best practices.

---

## Project Overview

This repository showcases practical implementations of:

- Spring Core
- Spring Boot
- Dependency Injection (IoC)
- Maven Project Management
- REST API Development
- Spring Data JPA
- Hibernate ORM
- Database Operations
- Query Methods
- HQL & Native SQL
- CRUD Operations
- Layered Architecture

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/rsaichandini-glitch/spring-java-hands-on.git
```

### Navigate to the Project

```bash
cd spring-java-hands-on
```

### Run the Application

```bash
mvn spring-boot:run
```

Or open the desired project in IntelliJ IDEA and run the main application class.
